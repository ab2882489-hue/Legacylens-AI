LegacyLens AI

LegacyLens AI is a “Legacy System Archeologist” that helps developers understand, document, and safely modify large, undocumented legacy codebases.

Enterprises often rely on millions of lines of old code written in languages like COBOL, Java, or C++. Over time, documentation is lost, and developers are afraid to touch the system due to unknown dependencies and side effects.

LegacyLens AI solves this by using Google Gemini’s long-context reasoning to analyze an entire repository at once and act as an intelligent system architect.

The Problem

- Massive legacy codebases with little or no documentation
- High risk when making even small changes
- Long onboarding time for new developers
- Expensive and manual documentation processes

The Solution

LegacyLens AI ingests a full code repository and enables:

- System-wide understanding of code structure
- Dependency and data-flow analysis
- Change impact prediction
- Automatic generation of technical documentation

 Why Gemini

This project is built for the Gemini Hackathon and leverages Gemini’s large context window to reason over thousands of files simultaneously — something traditional tools cannot do effectively.
